# COMMIT TFG 27/02/2026 #004
- Problema 1: Demasiado ruido (ImageElephant 35%, Harddrive1 25%, Newsgroups1 31%)
Epsilon demasiado pequeño ( muchos puntos quedan sin cluster.)

- Problema 2: Demasiados clusters fragmentados (Thioredoxin 15, musk2 9)
Epsilon demasiado pequeño para ese dataset ( cada bolsa forma su propio mini-cluster.)

- Problema 3: 1 solo cluster (Newsgroups1)
Epsilon demasiado grande ( todo colapsa, o epsilon demasiado pequeño -> sólo un núcleo sobrevive.)

-- Causa raíz común: min_pts=2 es demasiado permisivo. Con min_pts=2 cualquier par de bolsas forma un cluster, 
generando fragmentación extrema (Thioredoxin: 15 clusters). Subir min_pts forzaría clusters más densos y coherentes.

- Solución implementada: Grid_search para búsqueda de epsilon
La heurística clásica es min_pts = ln(n), pero para MIL con bolsas heterogéneas funciona
